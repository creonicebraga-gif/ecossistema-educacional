.# 🌟 Ecossistema Educacional Gamificado

Um projeto focado em apoiar e engajar estudantes de escolas técnicas na área de tecnologia (TI), combatendo a evasão escolar por meio da gamificação e de histórias inspiradoras.

## 🚀 Sobre o Projeto
Este sistema nasceu da percepção real de sala de aula sobre o ritmo acelerado dos cursos técnicos. Para evitar que os alunos (especialmente adolescentes) desistam diante das primeiras dificuldades, o ecossistema utiliza desafios de código baseados na vida de personalidades extraordinárias da computação.

### 🎮 Funcionalidades Principais
* *Gamificação:* Sistema de ganho de XP (xp_total) e conquistas de níveis de acordo com a resolução de desafios.
* *Histórias Inspiradoras:* Desafios de lógica baseados em pioneiros da tecnologia, como o *Desafio de Criptografia do Alan Turing*.
* *Mural de Conquistas:* Tabela dedicada ao histórico de medalhas do aluno para incentivar o progresso contínuo.

## 🛠️ Tecnologias Utilizadas
* *Frontend:* [Astro Framework](https://astro.build) & JavaScript (Vanilla JS) para uma interface leve e veloz.
* *Hospedagem:* [Vercel](https://vercel.com) para deploys contínuos e estabilidade.
* *Banco de Dados:* [Supabase](https://supabase.com) para modelagem relacional das tabelas de alunos, escolas e jogos.
